# IPL Analytics Dashboard

## 📊 Project Overview

An interactive IPL analytics dashboard built using Microsoft Excel to analyze IPL match data from 2008–2024.

The project focuses on match trends, team performance, toss decisions, venues, and Player of the Match awards.

## 🎯 Objectives

- Analyze IPL match trends across seasons
- Compare team performance
- Analyze toss decisions and match outcomes
- Identify frequently used venues
- Analyze Player of the Match awards
- Build an interactive dashboard using Excel slicers

## 🛠️ Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Excel formulas
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Features

- Total Matches: 1,095
- Seasons: 17
- Teams: 19
- Venues: 58
- Super Over Matches: 14
- Matches Played by Season
- Toss Decision Distribution
- Top 10 Venues by Matches
- Top 10 Player of the Match Awards
- Team Win Percentage
- Interactive Season, Team and Toss Decision slicers

## 🔍 Key Insights

- 1,095 IPL matches were analyzed across 17 seasons.
- Mumbai Indians recorded the highest number of wins with 144.
- The toss winner won approximately 50.59% of matches.
- Eden Gardens hosted the highest number of matches with 77.
- AB de Villiers received 25 Player of the Match awards.

## 📁 Dataset

IPL match-level data covering the 2008–2024 seasons.

The analysis uses match-level information such as:

- Season
- Teams
- Winner
- Toss Winner
- Toss Decision
- Venue
- Player of the Match
- Match Result
